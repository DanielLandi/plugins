# Writing original songs

Every song is an original. Suno's filter blocks lyrics it recognises (even public-domain texts), and a famous line
over new verses sounds uncanny anyway. The goal is a song listeners believe is a real record they have simply
never heard.

## Rules
1. **No borrowed material.** Never quote another song's lines, refrains or hooks, and never use a well-known
   song's title.
2. **No private references.** No real people's names, inside jokes, home addresses, pets. `validate` checks the
   workspace's optional `private-names.txt` (one name per line), but judgment comes first.
3. **Check the title.** Before drafting, WebSearch `"<title>" song`. If a well-known song already uses it, pick
   another.
4. **Sound like the era.** Use the genre recipe's idiom, concrete images over clichés, and a chorus built on the
   title.
5. **Keep it shareable.** No explicit content unless the user asks for it and the genre calls for it.
6. **Length.** 2–4 minutes: two or three verses, a repeated chorus, one bridge or instrumental break. Keep lyrics
   well under 3000 characters.
7. **Language:** English unless the user asks otherwise; section tags stay English.
8. `kind: original` in every spec.
