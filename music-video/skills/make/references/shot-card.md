# Shot card

One card per camera move (`shot-design.md`). Fill it in before keying anything; its first sentence goes into the
section's `STORYBOARD.md` entry, the rest into the scene's notes.

**The move:** From [start frame], [move] so we [reveal / follow / feel] [what], landing on [end frame] on [word or beat].

| | Start waypoint | End waypoint |
|---|---|---|
| Frame and song time | | |
| The beat or line it serves | | |
| Subject and size (ECU / CU / MCU / MS / WS / EWS) | | |
| Place in frame (which third, which side, lead room) | | |
| Angle (height, how far down or up, which side of the subject) | | |
| Lens (vertical field of view) | | |
| Foreground / midground / background | | |
| Edges (what crosses, what's cropped where) | | |

- **Axes:** the leading axis, and the ones supporting it (e.g. the push leads, a rise supports).
- **Passes close to:** the near object that gives parallax, and how far it is from the lens.
- **Speed profile:** starts on [beat], peaks into [accent], lands on [beat]. One rise, one fall.
- **In and out:** continuous / a push into a shape / through real geometry / a whip / a cut behind a full-frame push
  (and, at a scene change, the `cuts.ts` entry it becomes: carrier and transition).
- **Jolts:** none, unless the video's jolts answer is yes (`LOOK.md`); then what kicks, on which hits.
- **The user's words for this shot (verbatim, with when they said them):**
- **Checks run:** smoothness, image speed, seen share, size and place at each waypoint, the stills looked at.
